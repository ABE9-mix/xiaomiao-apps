# 摩斯码训练器

单文件整片固件：`dist/xiaomiao-morse-merged.bin`（从 `0x0` 刷）
源码：`main/main.c` + `main/ark12_font.c` / `main/ark24_font.c`（自动生成）

## 功能：五个模式（长按 LEFT / RIGHT 切换）

| 模式 | 做什么 | 按键 |
|---|---|---|
| **查询** | 52 项全表游标（A–Z / 0–9 / 标点），显示字符 + 点划并发声 | `U/D` ±1，`L/R` ±10，`A` 发声，`B` 隐藏字符自测 |
| **顺序** | 按 Koch/LANL 顺序（K M R S U A P T L O W I . N J E F 0 Y V , G 5 / Q 9 Z H 3 8 B ? 4 2 7 C 1 D 6 X）逐个学，带进度 | `U/D` 上/下一个（自动发声），`A` 重播，`B` 回到第一个 |
| **听辨** | **播放一个随机字的莫斯音 → 从 5 个候选字里选**（6 个键打不了字，所以是听音选字）；带正确率/连击 | `L/R` ±1，`U/D` ±5，`A` 提交，`B` 重播 |
| **发报** | 按键发报并自动解码成字符 | 单键：按住 `A` 按时长判点/划；双键：`A`=点 `B`=划；`B` 清空（单键） |
| **设置** | 列表：键位引导（图形 d-pad 子页）/ 声音开关 / 速率 | `U/D` 选，`A` 进入或切换，`B` 返回 |

全局：**长按 `L/R` 换模式**，**长按 `A` 循环 WPM**（5/8/10/12/15/20），发报模式下**长按 `U` 切单/双键**。
模式 / WPM / 单双键 / 学习进度 / 声音开关全部写 NVS。板载 LED1 按键时亮、LED2 发声/发报时亮。

## 实现要点
- 发声：1ms `esp_timer` 驱动"莫斯发声队列"（点=1 单位、划=3、符号内间隙=1、字符间隙=3），点长 `1200/WPM` ms。
- 发报键：同一 1ms 定时器采样，单键按时长判点/划，静默超 3 点判为一个字符并解码。
- 界面：方舟 12px + 24px；卡式版面、模式指示点；提示只留"非直觉"的长按操作，完整键位图在设置页。
- 开机字体自检：取几个字把 1bpp 展开成 A8 后数像素点，日志给 `PASS/FAIL` 判定。
